# Global Visions Track Store

Downloadable Assetto Corsa tracks, sold with a licence tied to the buyer's Steam ID
(personal) or to a venue's machines (commercial).

| Part | Where | Runs on |
|---|---|---|
| Store pages (EN at `/store/`, IT at `/it/store/`) | `store/`, `it/store/`, generated by `tools/build-store.mjs` from `store-src/tracks.json` | Vercel, static |
| API, licences, downloads, admin | `worker/` | Cloudflare Worker + D1 `gv-store` + R2 `gv-tracks` |
| Race server check | `assettoserver-plugin/` | AssettoServer plugin on each race server |
| In-game check | `csp-integration/` | CSP Lua script inside each track, wired by the track author |
| Contract between all of them | `docs/store/CONTRACT.md` | |

## How a purchase works

1. The visitor browses `/store/`, opens a track, picks personal or commercial.
2. Personal: "Sign in through Steam" (OpenID, Steam returns only the Steam ID).
   Commercial: no Steam account needed.
3. Stripe Checkout (live, Stripe Tax for EU VAT, email collected there, consent to
   immediate delivery and loss of the withdrawal right).
4. Stripe calls the Worker webhook. The Worker re-reads the session from Stripe,
   checks the paid price id against the D1 catalog and creates the licence.
5. The buyer lands on `/store/account/`, which lists their tracks with 15 minute
   download links. Each download gets its own copy id written into
   `extension/gv_licence.ini`, so a leaked build can be traced from the admin view.
6. In game, the track's Lua script activates the machine and validates periodically.
   On race servers, the AssettoServer plugin refuses players without a licence.
7. A full refund or a dispute switches the licence off everywhere.

## Layers of protection, from strongest to weakest

1. **Race server check** (AssettoServer plugin): runs on the server, with Steam
   authentication on, so the Steam ID cannot be faked. Online races stay closed to
   non-buyers. This is the layer that matters most.
2. **Traceable copies**: every download is unique. If a build leaks, the admin view
   shows which licence it came from, and that licence can be revoked.
3. **In-game check** (CSP Lua): keeps the features that matter (lights, animations,
   evolving grip, timing) off without a valid licence, with a 72 hour offline grace.

Honest limit: any client-side check can be bypassed with enough effort. The goal is
to make sharing inconvenient, trace who does it, and keep online races closed. The
Assetto Corsa community dislikes heavy DRM, so personal licences allow 2 machines,
a buyer can free a machine slot once a week from the account page, the client keeps
working offline for 72 hours, and support is one email away.

## Previewing without the Worker

Add `?demo=1` to any store URL on the Vercel preview: the pages fake the API
(signed-in user, licences, machines, a commercial key, admin data) so every screen
can be reviewed before the Worker is deployed.
