Personal licence

Commercial licence

Online checks

When the track loads, and from time to time while you drive, a script in the track asks our licence server whether your licence is active. It sends only the licence id, your Steam ID (or the commercial licence key) and an opaque machine identifier generated by the track. If our server cannot be reached, the track keeps working for a grace period, so an outage on our side never stops you from driving.

Race servers that use our server check let in only drivers with a valid licence for the track. Which servers use it is the server owner's choice.
